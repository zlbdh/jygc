# WEB-001 平台审核通过后企业侧状态同步

## 类型

- 文档型回归
- 后续自动化：Playwright

## 目标

验证 `admin-web -> backend -> web-portal` 的审核同步链路是否完整。

## 输入

- 平台端存在一个待审核的企业入驻、服务上架或商品上架记录
- 企业端有对应详情页或状态列表

## 步骤

1. 在 `admin-web` 完成审核通过
2. 观察 `backend` 是否完成状态变更和同步
3. 登录 `web-portal` 查看企业端状态展示

## 预期结果

- 平台端审核状态正确落库
- 后端同步链路无异常
- 企业端状态、时间、处理结果一致

## 风险点

- 平台状态枚举与企业端状态枚举不一致
- 审核备注未同步
