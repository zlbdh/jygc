# Acceptance

- Documentation and human-facing script messages use American English.
- Commands, schema keys, repository identities, permissions, and control flow retain their meanings.
- Remaining non-English text is individually documented where behavior or source data requires retention.
- Validation evidence records available checks and environmental limits honestly.
- No deployment or production operation is part of this change.

Rollback: revert the localization commit without changing prior repository history.
